GEPISEG — Referência da API

Toda função de gepiseg-api.js: filtros aceitos, JSON devolvido, e execução ao vivo nesta página. —

Instância

<script src="js/dados.js"></script>
<script src="js/gepiseg-api.js"></script>

const api = GepisegAPI.criar();        // ou: await GepisegAPI.carregar();
api.artigos.listar({ q: 'phishing' }).then(r => r.results);

Listagem devolve { info, results }; item devolve o objeto cru; relação viaja como caminho de arquivo; filtro sem resultado é 404 com { error }. A lib não renomeia nem calcula campo — o JSON já é a resposta.
